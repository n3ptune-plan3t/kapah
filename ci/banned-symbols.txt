#
# kapah renders with QPainter on the CPU. The moment a QOpenGLWidget,
# QQuickWidget, QQuickItem or a .qml file sneaks in, we start depending on an
# RHI backend that does not exist under llvmpipe/no-DRI, and the RSS floor in
# section 0 of the roadmap becomes unreachable.
#
# Each entry is "<extended-regex>[TAB]<why>". Blank lines and lines starting
# with '#' are ignored. Run with: ci/check-banned-symbols.sh
